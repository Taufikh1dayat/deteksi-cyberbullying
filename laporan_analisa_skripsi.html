Imbalance dataset 55.5% Bullying vs 44.5% Aman — tidak perlu SMOTE AMAN
Rasio 55:44 tergolong mild imbalance. Penguji mungkin bertanya kenapa tidak pakai SMOTE/oversampling. Jawaban: threshold 60:40 umumnya belum kritis; F1-Score kedua kelas seimbang, membuktikan model tidak bias ke kelas mayoritas.
TF-IDF defaultparams — tidak ada n-gram eksplisit di notebook training POTENSIAL PERTANYAAN
Notebook memanggil TfidfVectorizer() tanpa parameter apapun — pakai default: unigram only (ngram_range=(1,1)), tidak ada limit fitur. Ringkasan menyebut "TF-IDF n-gram" tapi kode hanya unigram. Perlu diklarifikasi di naskah.
→ Ubah klaim "n-gram" di naskah menjadi "TF-IDF unigram" ATAU retrain dengan ngram_range=(1,2) untuk bigram
Benchmark latensi: diukur via time.perf_counter() — metode valid untuk skripsi VALID
Kode di app.py baris 233-244 menggunakan time.perf_counter() secara terpisah per model (preprocessing, SVM, NB). Ini adalah metodologi yang tepat dan dapat dipertanggungjawabkan. 🎓 Prediksi Pertanyaan Penguji + Jawaban Rekomendasi
"Kenapa tidak pakai deep learning (BERT/IndoBERT) yang lebih akurat?"
Jawaban: SVM dengan TF-IDF telah mencapai 86.75% akurasi pada dataset 13.165 data — kompetitif dengan baseline pre-BERT. Keunggulan pendekatan ini: (1) interpretabilitas langsung via LIME, (2) latensi inferensi sub-1ms yang tidak mungkin dicapai BERT pada CPU, (3) tidak memerlukan GPU untuk deployment. Penelitian ini secara eksplisit membandingkan dua algoritma ML klasik untuk aspek kecepatan real-time, bukan kompetisi akurasi mutlak.
"Dataset hanya dari Twitter 2019 — apakah masih relevan untuk deteksi sekarang?"
Jawaban: Dataset Ibrohim & Budi (2019) adalah gold-standard untuk NLP Bahasa Indonesia dengan anotasi multi-label yang tervalidasi secara akademik (CC BY-NC-SA 4.0). Pola bahasa ujaran kebencian BI bersifat relatif stabil. Penggunaan kamus alay terkini (new_kamusalay.csv) mengakomodasi evolusi bahasa gaul kontemporer. Validasi real-world dilakukan melalui scraping konten aktual pada demo.
"Mengapa imbalance 55:44 tidak ditangani dengan SMOTE?"
Jawaban: Rasio 55.5% : 44.5% tergolong mild imbalance (threshold kritis umumnya di atas 70:30 atau 80:20). F1-Score kedua model di atas 83% tanpa teknik oversampling membuktikan tidak ada bias signifikan ke kelas mayoritas. SMOTE pada data teks dengan TF-IDF juga bermasalah karena menginterpolasi vektor sparse — bisa menghasilkan dokumen sintetis yang tidak bermakna secara linguistik.
